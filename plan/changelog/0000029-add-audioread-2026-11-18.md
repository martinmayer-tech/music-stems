# Changelog (0000029-add-audioread, 18 Nov 2026)

**Feature:** Add audioread to the image and the separation extra
**Version:** 0.8.1
**PR:** 15

## What changed

- The `separation` extra in `pyproject.toml` pins `audioread==3.1.0` beside the engine.
- The `Dockerfile` gains the build argument `AUDIOREAD_VERSION` and installs `audioread` in the engine's layer.
- Two tests check the install, and one test keeps the two pins equal.
- Added ADR 0009 and updated the component docs and the living docs.
- Removed backlog entry 0000023, which this run folds in.

## Why

A job in the built image ended `failed` with `No module named 'audioread'`. `audio-separator` 0.48.0 imports `audioread`, and `librosa` 1.0.1 no longer installs it.

## Deviations

- Entry 0000023 suggested a change to the `separation` extra alone. The `Dockerfile` does not install that extra, so the run changes both files.
- The run started in the session that delivered initiative 0000001, with no context clear.
- The docs edit pass ran inline, with no reviewer subagent.

- Two later jobs in the same container lost their stems, because the reused separator keeps the first job's folder. Backlog entry 0000031 holds that fault. This run does not fix it.
