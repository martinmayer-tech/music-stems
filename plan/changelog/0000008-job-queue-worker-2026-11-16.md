# Changelog (0000008-job-queue-worker, 16 Nov 2026)

**Feature:** Add the job queue and worker
**Version:** set by the merge queue at merge
**PR:** pending

## What changed

- Added the `jobs` table and `JobStore` in `stem_service/jobs.py`, with `claim_next()` and `recover()`.
- Added `Worker`, `start_workers`, and the `ModelPool` in `stem_service/worker.py`.
- Added `stem_service/config.py` for `STEMS_DATA_DIR`.
- Added ADR 0004, the `stem-service` data contract, and updated the component docs and living docs.

## Why

Each `split()` call loaded its models again, and two calls could compete for one GPU. The service needs a queue that survives a restart and a worker that loads each model once.
