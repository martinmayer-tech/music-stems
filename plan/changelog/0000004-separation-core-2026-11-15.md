# Changelog (0000004-separation-core, 15 Nov 2026)

**Feature:** Add the two-pass separation core
**Version:** set by the merge queue at merge
**PR:** pending, updated at Step 9

## What changed

- Added `split(mix_path, out_dir, full_stems=False)` to `stem_core`. Pass 1 writes vocals and instrumental. Pass 2 adds drums, bass, and other.
- Added the `STEMS_MODEL_DIR` setting, WAV output, and absolute returned paths.
- Added a `separation` extra in `pyproject.toml` that pins `audio-separator[cpu]==0.48.0`.
- Changed the `python` CI job to install the `separation` extra.
- Added one `slow` test that runs the real model. The default `pytest` run skips it.
- Added ADR 0002 and updated the component docs and living docs.

## Why

Nothing wrapped `audio-separator`. Steps 3, 4, and 7 call this function.

## Deviations

- Pass 2 renames its vocals stem to `residual_vocals` and deletes it. Without this, it overwrites the pass 1 vocals file.
- `split()` sorts the pass 1 stems by name, because the real separator lists the instrumental first.
- The real-model test checks sound in the instrumental only, because a pure tone has no voice.
- The design lists `pyproject.toml` without the `./` prefix that step 1 recorded for root files.
