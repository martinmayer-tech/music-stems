**Version:** set by the merge queue at merge

## What changed

- Added the page to `stem-web`: `stem_web/static/index.html`, `app.js`, and `style.css`, with no build step.
- Added `stem_web.static_dir()`, which names the page folder.
- Added `GET /` and a `/static` mount to `create_app()` in `stem-service`.
- The page uploads a file with the full stems option, lists jobs, and polls every two seconds while a job is `queued` or `running`.
- A `done` job shows one player and one download link for each stem.
- Added ADR 0006, the OpenAPI spec for the page routes, and updated the component docs and the living docs.

## Why

The API had no user interface. The goal is a self-hosted replacement for a hosted web tool.
