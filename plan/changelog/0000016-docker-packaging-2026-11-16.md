# Changelog (0000016-docker-packaging, 16 Nov 2026)

**Feature:** Add the Docker image and compose file
**Version:** set by the merge queue at merge
**PR:** pending

## What changed

- A `Dockerfile` builds one image from `python:3.12-slim` with FFmpeg. It runs `python -m stem_service` as the non-root user `stems`.
- The build argument `STEMS_EXTRA` selects the `cpu` or `gpu` extra of `audio-separator`. The argument `AUDIO_SEPARATOR_VERSION` repeats the pin of `pyproject.toml`.
- `compose.yaml` publishes `127.0.0.1:8000` and mounts the named volumes `models` and `data`. `compose.gpu.yaml` selects the GPU extra and reserves an NVIDIA device.
- A `.dockerignore` file keeps the plan, the pack, and caches out of the build context.
- The CI workflow gains a `docker` job that builds the CPU image on a pull request.
- Added ADR 0008, three test files, and updated the component docs and the living docs.

## Why

Running the service needed a manual Python and FFmpeg install, and a container without a volume downloaded every model again.

## Deviations

- The brief and design declared build target `docker`. The tests run on the host with pytest, so the agent changed the target to `local`.
- The `gate-write` hook ignores a component path with no slash, so the design lists the root files with a `./` prefix.

- The first image build failed because `diffq` has no wheel and needs `gcc`. The Dockerfile now installs `gcc` and `libc6-dev` in the `pip install` layer and removes them there. The chart lists no compiler, so the agent records the use as a build-only tool of the approved `audio-separator` library.

## Validation results

- `ruff check .` exits 0. `pytest` gives 174 passed and 1 deselected. The full pack suite gives 0 new failures and 62 inherited failures.
- The CPU image built and the compose stack served the page. A restart and a down and up kept the job list and a downloaded model.
- A job in the image fails with `No module named 'audioread'`. Backlog entry 0000023 holds the fix, which needs a dependency approval.
- The agent built no GPU image.
